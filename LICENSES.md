# Licensing

This project is open so that anyone can use, study, build and improve it, and so that improvements stay open for everyone.

|---|---|---|
| Software and firmware | GNU General Public License v3.0 or later (GPL-3.0-or-later) | `software/`, `firmware/` |
| Hardware designs (schematics, circuit boards, enclosures, mechanical parts, button-top models) | CERN Open Hardware Licence v2, Strongly Reciprocal (CERN-OHL-S-2.0) | `hardware/` |
| Documentation, concept documents and guides | Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0) | `docs/`, `CONCEPT.md`, `README.md` |

In plain language: you may use, change, make and sell anything in this project. If you distribute a changed version, or a product built from it, you must share your changes under the same licence.

The full licence texts are in the `LICENSES/` folder:

- `LICENSES/GPL-3.0-or-later.txt`
- `LICENSES/CERN-OHL-S-2.0.txt`
- `LICENSES/CC-BY-SA-4.0.txt`

The project name and logo, once chosen, are not covered by these licences. They are reserved so that people can tell official and certified products apart from others. Products built from these designs are welcome, but must use a different name.
