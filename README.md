# Open Modular AV and Control System

An open, low-cost, accessible, modular system for audio, video, lighting and control, aimed at churches, schools, universities, community venues, bedroom studios and streamers.

Build exactly the system you need from small blocks, add to it over time, and configure it without being a specialist. Every part is designed to be usable with a screen reader and by touch.

This project is at the concept and early prototyping stage.

## The idea in brief

- Metal I/O modules for audio, video, lighting, control and power that join side by side or by ordinary Ethernet cable.
- Hubs that range from a simple USB audio interface to full mixing and video processing.
- A modular control surface of knobs, buttons, faders and displays, with touch-to-identify speech on every control and swappable tactile button tops.
- One cable type everywhere: standard Ethernet.
- Open protocols (AES67, PTP, OSC, AES70), open-source software and open hardware.
- Run as a not-for-profit, close to cost, with a trade-in and refurbished program.
