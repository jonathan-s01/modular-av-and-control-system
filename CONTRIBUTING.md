# Contributing

Thank you for your interest. All kinds of help are welcome: ideas, feedback, accessibility testing, documentation, code, hardware design and button-top designs.

## Ways to help

- Open an issue to report a problem or suggest an idea.
- Start a discussion about how you would use the system or what you need from it.
- Submit a pull request with code, designs or documentation.

## Accessibility

Accessibility is a core requirement, not an extra. Any interface you contribute must work fully with a keyboard and a screen reader. If you use assistive technology, your feedback is especially valuable.

## Licensing of contributions

You keep the copyright to your contributions. By contributing, you agree that your work is released under the licence that covers that part of the project (see LICENSES.md). This keeps the project open for everyone.

## Sign-off (Developer Certificate of Origin)

Each commit must include a sign-off line confirming you have the right to submit the work under the project licence, as described in the Developer Certificate of Origin (https://developercertificate.org):

```
Signed-off-by: Your Name <your.email@example.com>
```

Git adds this line automatically when you commit with the `-s` option:

```
git commit -s -m "Describe your change"
```

## Code of conduct

Be respectful, patient and welcoming. This project is for people of all abilities and backgrounds.
